# Shop

The shop: browse, enquire, order.

## Install the app (free, no store needed)

**Open the app page: https://romal10.github.io/shop/** and press **Install now**.

| Device | How |
|---|---|
| **Android** | Open the page in Chrome → **Install now** (or ⋮ menu → *Install app*) |
| **iPhone / iPad** | Open the page in **Safari** → Share icon → *Add to Home Screen* |
| **Windows** | Open the page in Edge or Chrome → **Install now** (or the install icon in the address bar) |
| **Mac** | Chrome / Edge → **Install now**; Safari → Share → *Add to Dock* |

You can also just open the page and use it in the browser — no install required.

## About this repository

Only the static launcher page lives here. The application itself (all of its code and data) is not published and runs
privately. `config.json` holds the address the launcher forwards to.
